## Findings / Выводы

**Supported mathematics / Математика подтверждается.** On the unit circle, `(cos θ, sin θ)` correctly gives the point's `(x, y)` coordinates; sine and cosine stay in `[-1, 1]`. The equalities `sin(θ + 2π) = sin θ` and `cos(θ + 2π) = cos θ` are correct, and `2π` is the fundamental period of both parent functions. The lesson correctly labels `[-2π, 2π]` as the lab's display window, not as the functions' domain. / Для единичной окружности запись `(cos θ, sin θ)` правильно задаёт координаты `(x, y)`; синус и косинус лежат в `[-1, 1]`. Равенства `sin(θ + 2π) = sin θ` и `cos(θ + 2π) = cos θ` верны, а `2π` — основной период обеих исходных функций. Урок правильно уточняет, что `[-2π, 2π]` — окно тренажёра, а не область определения функций.

**Worked value / Разобранное значение.** `5π/6 = 150°` lies in quadrant II, with reference angle `π/6` (30°). Thus `(cos(5π/6), sin(5π/6)) = (−√3/2, 1/2)`, so cosine is negative and sine is positive. OpenStax §5.2 works the equivalent `150°` example and gives these exact values. / `5π/6 = 150°` лежит во II четверти; опорный угол равен `π/6` (30°). Поэтому `(cos(5π/6), sin(5π/6)) = (−√3/2, 1/2)`: косинус отрицателен, синус положителен. В §5.2 OpenStax разобран эквивалентный пример с `150°` и приведены те же точные значения.

**Answer-key defect / Ошибка ключа.** The Russian options are Negative / Zero / Positive and `Ответ 3` correctly selects the third option. The English options have the same order, but `Answer 2` selects the second option, “Zero”; the accompanying explanation says the answer is positive. The app's Markdown parser converts the displayed ordinal to a zero-based option index by subtracting one (`LearningViews.swift`, `CurriculumCatalog` parsing), confirming that Markdown answer numbers are one-based. The follow-up below records correction of the English key to `3`. The separate interactive unit-circle lab currently stores the positive option at zero-based index `2`; this audit does not test its runtime behavior. / Русские варианты идут как «Отрицательный / Нулевой / Положительный», и `Ответ 3` правильно указывает на третий. Английские варианты стоят в том же порядке, но `Answer 2` выбирает второй — «Zero»; при этом пояснение говорит, что правильный знак положительный. Парсер Markdown в приложении преобразует показанный номер варианта в индекс с нуля вычитанием единицы (`LearningViews.swift`, разбор в `CurriculumCatalog`), то есть номера ответов в Markdown считаются с единицы. Исправление английского ключа на `3` зафиксировано ниже. В отдельном интерактивном тренажёре положительному варианту соответствует индекс `2`; фактическое выполнение этого экрана здесь не проверялось.
