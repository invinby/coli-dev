## Focused follow-ups / Точечные дальнейшие правки

1. **Trainer wording / Формулировка тренажёра.** In `macOS/ColiDev/App/L10n.swift` (`biology.moleculeLab.info.enzyme`), change “An enzyme is a protein / Фермент — белок” to “This example is a protein enzyme / В этом примере фермент — белок” or “Many enzymes are proteins / Многие ферменты — белки.” RNA can itself be catalytic: the official NLM MeSH entry defines catalytic RNA as RNA with catalytic activity that can function as an enzyme. OpenStax §3.4 itself says enzymes are “usually” proteins. This nuance does not change the current lesson quiz answer. / В `macOS/ColiDev/App/L10n.swift` (`biology.moleculeLab.info.enzyme`) заменить общее «Фермент — белок» на «В этом примере фермент — белок» или «Многие ферменты — белки». РНК тоже может катализировать реакции: официальная запись MeSH определяет каталитическую РНК как РНК с каталитической активностью, способную действовать как фермент. §3.4 OpenStax также говорит, что ферменты «обычно» являются белками. Это уточнение не меняет правильный ответ текущего теста урока. [NLM MeSH: RNA, Catalytic](https://www.ncbi.nlm.nih.gov/mesh/68016337); [OpenStax Biology 2e §3.4](https://openstax.org/books/biology-2e/pages/3-4-proteins).

2. **Reaction-model clarity / Ясность схемы реакции.** `BiomoleculeLab` always shows generic “small components → large molecule” plus water released/used, even when the selected example is a triglyceride. The lesson and UI caveat correctly say lipids are not all polymers and bonds use different mechanisms, so this is not a contradiction stated as fact; nevertheless, label the drawing explicitly as an abstract example or make its components track the selected molecule (especially glycerol + three fatty acids for triglyceride). The app was not run, so this is a source/code inspection finding only. / `BiomoleculeLab` всегда показывает общие «малые компоненты → крупная молекула» и выделение/использование воды даже при выборе триглицерида. Оговорки урока и интерфейса верно сообщают, что липиды не все являются полимерами и связи образуются разными механизмами; поэтому это не прямая ошибка в тексте, но схему лучше пометить как абстрактный пример либо подстраивать под выбранную молекулу (для триглицерида показывать глицерол и три жирные кислоты). Приложение не запускалось — это вывод только по исходному коду.

3. **Lesson text / Текст урока.** No factual correction is required based on this audit. When the lesson is next edited, consider changing the challenge wording from “an amino-acid chain folds into an enzyme” to “an amino-acid chain folds into a protein enzyme” to make clear that this example is about a protein catalyst, without implying that every enzyme is a protein. / По итогам этой проверки обязательная фактическая правка текста урока не нужна. При следующем редактировании можно уточнить задачу: вместо «цепь аминокислот сворачивается в фермент» написать «цепь аминокислот сворачивается в белковый фермент», чтобы было ясно: пример относится к белковому катализатору и не утверждает, что каждый фермент — белок.
