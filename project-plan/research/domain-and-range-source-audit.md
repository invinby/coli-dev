**Scope / Объём:** Checked both language versions for the real-domain and range derivations, interval conventions, reciprocal example, taxi arithmetic, interactive-lab consistency, answer-key mapping, translation parity, and directness/freshness of the citation. This is a source and code inspection only; the lesson and app were not edited or run. / Проверены русская и английская версии: область определения и множество значений над вещественными числами, интервальная запись, пример с обратной функцией, расчёт для такси, соответствие интерактивному тренажёру, ключ ответа, смысловой паритет переводов, прямота и актуальность ссылки. ## Findings / Выводы

### 1. Definite answer-key defect in both languages / Подтверждённая ошибка ключа в обоих языках

**EN:** The options are ordered `x ≥ 8`, `x ≤ 8`, `Every real x`, but both `Ответ` and `Answer` contain `1`. The explanation correctly derives `x ≤ 8`, which is option 2. The app parses the Markdown answer as one-based and subtracts one to get the original option index (`LearningViews.swift`, lines 243–244), so answer `1` selects the first, incorrect choice. Choice shuffling in the UI retains and checks that original index. The key should be `2` in both sections. The generic route validator only checks that the numeric key is within the option count, so it does not catch this semantic mismatch. / **RU:** Варианты расположены как `x ≥ 8`, `x ≤ 8`, `Все вещественные x`, но в обоих разделах `Ответ` и `Answer` стоит `1`. Разбор правильно выводит `x ≤ 8` — это второй вариант. Приложение трактует номер Markdown-ответа как нумерацию с единицы и вычитает 1 для исходного индекса варианта (`LearningViews.swift`, строки 243–244), поэтому ключ `1` выбирает первый, ошибочный вариант. Перемешивание вариантов в интерфейсе сохраняет проверку по исходному индексу. В обоих разделах ключ должен быть `2`. Общая проверка маршрутов проверяет лишь, что номер попадает в диапазон вариантов, и не обнаруживает смысловое расхождение.

### 2. Mathematics and interval notation are correct / Математика и интервальная запись верны

**EN:** For real inputs, `8 − x ≥ 0` gives `x ≤ 8`, hence domain `(-∞, 8]`; every nonnegative output is reached, with no upper bound, so the range `[0, ∞)` is correct. For `1/(x − 3)`, `x = 3` is excluded and zero is not an output. The bounded square model `y = x²` on `[-N, N]` has range `[0, N²]`. These claims follow the even-root, reciprocal, and quadratic domain/range rules in OpenStax §3.2. Its interval convention also matches the lesson: included finite endpoints use square brackets and unbounded endpoints use parentheses. / **RU:** Для вещественных входов условие `8 − x ≥ 0` даёт `x ≤ 8`, значит область определения — `(-∞, 8]`; каждое неотрицательное значение достигается, верхней границы нет, поэтому множество значений `[0, ∞)` верно. Для `1/(x − 3)` исключается `x = 3`, а ноль не является выходом. Для ограниченной модели `y = x²` на `[-N, N]` множество значений — `[0, N²]`. Эти выводы соответствуют правилам OpenStax §3.2 для чётного корня, обратной функции и квадратичной функции. Урок верно использует квадратные скобки для включённых конечных границ и круглые скобки для бесконечности.

### 3. Taxi example and interactive lab agree / Пример с такси и тренажёр согласованы

**EN:** Under the lesson's explicitly stipulated model `C(k) = 2 + 3k` for `0 ≤ k ≤ 4`, the minimum and maximum are 2 and 14. This is internally consistent as an illustrative fare model, not a claim about a real taxi tariff. The shipped `DomainRangeLab` uses the same equation: taxi input `[0,N]` and output `[2, 2 + 3N]`; square input `[-N,N]` and output `[0,N²]`; square-root input `[0,N²]` and output `[0,N]`. These match the lesson text and chart calculations for `N ≥ 1`. / **RU:** При явно заданной в уроке модели `C(k) = 2 + 3k` для `0 ≤ k ≤ 4` минимальная и максимальная стоимость равны 2 и 14. Расчёт согласован внутри учебного примера; это не заявление о тарифах реального такси. Реальный `DomainRangeLab` использует ту же формулу: для такси вход `[0,N]`, выход `[2, 2 + 3N]`; для квадрата вход `[-N,N]`, выход `[0,N²]`; для корня вход `[0,N²]`, выход `[0,N]`. Это совпадает с текстом и вычислениями графика урока при `N ≥ 1`.

### 4. RU/EN content parity and source / Паритет RU/EN и источник

**EN:** The Russian and English versions present the same concepts, examples, bounds, choices, and explanation. Their shared citation points directly to the relevant official OpenStax *Algebra and Trigonometry 2e* section (§3.2), which covers domains from even roots and zero denominators, interval notation, graph-derived range, and the quadratic/square-root/reciprocal toolkit functions. No additional source is needed for these stable algebra claims. The taxi equation is a declared toy model and is correctly presented conditionally. The lesson originally said `source_checked: 2026-10-05`; the cited page was checked on 2026-10-12 and the metadata was refreshed after the answer-key correction. / **RU:** Русская и английская версии содержат одинаковые понятия, примеры, границы, варианты и разбор. Общая ссылка ведёт непосредственно к нужному официальному разделу §3.2 учебника OpenStax *Algebra and Trigonometry 2e*: там рассматриваются ограничения чётного корня и нулевого знаменателя, интервальная запись, чтение множества значений по графику и базовые квадратичная, корневая и обратная функции. Для этих устойчивых алгебраических утверждений дополнительный источник не требуется. Формула такси — явно заданная учебная модель, и условная формулировка это показывает. Изначально в уроке стояла дата `source_checked: 2026-10-05`; официальный раздел проверен 2026-10-12, после исправления ключа дату метаданных обновили.
