# Official learning sources and freshness / Официальные источники обучения и актуальность

**Checked / Проверено:** 2026-10-18. Source/code inspection only; no new integrations or Mac beta runtime check. / Только обзор источников и кода; новые интеграции и проверка бета-версии на Mac не выполнялись.

## What is actually wired / Что уже подключено

- `01_Projects/knowledge_index.py` indexes local Markdown under `02_Areas/` and Markdown/text under `03_Resources/Cheatsheets/`; changed local files refresh at backend startup and tutor retrieval. This index does not crawl the open web. / Индексирует локальные курсы и шпаргалки; переиндексирует изменения на старте и при поиске для тьютора. Сам этот индекс веб не сканирует.
- `01_Projects/trusted_sources.py` separately checks exact approved hosts/URLs cited in lesson Markdown, records HTTP status, ETag/Last-Modified and content-change signals. `01_Projects/orchestrator.py` runs checks while backend is alive (default on, normally every 24 h; transient failures retry after 6 h); manual endpoint: `POST /knowledge/sources/check`. No background checks while backend is closed. / Отдельный монитор проверяет точные разрешённые ссылки, сохраняет HTTP-статус, ETag/Last-Modified и сигналы изменения. Он работает только вместе с backend; ручной endpoint указан выше.
- Web text RAG is narrower: only selected exact paths from Python docs, SQLite, MedlinePlus Genetics, NHGRI, NIST and one CC BY eLife XML source are eligible. OpenStax, Cambridge, British Council, Animal Diversity Web and NCBI Bookshelf may be source-monitor references, but are not current full-text RAG sources. Changes require editorial review; code does not verify claims or rewrite lessons. / В веб-RAG разрешены лишь отдельные страницы этих источников. Изменения требуют редакторской проверки; код не подтверждает факты и не переписывает урок.
- Gap: six intro lessons are assembled from `macOS/ColiDev/App/L10n.swift`, outside Markdown source inventory; [intro audit](intro-catalog-source-audit.md) found no lesson-level citations for those cards. / Шесть вводных карточек лежат в `L10n.swift`, вне Markdown-реестра; [аудит](intro-catalog-source-audit.md) нашёл пробел в цитировании карточек.

## Standards, data and updates / Стандарты, данные и обновления

- If Uzbekistan is the launch curriculum target: [Lex.uz Resolution 157 (2024)](https://lex.uz/uz/acts/-6854214) defines state-standard development/approval; [UZBMB catalogue](https://uzbmb.uz/page/o_dasturlar) says the Ministry provided programmes; [Qabul-2026](https://uzbmb.uz/page/qabul2026_2027) links 2026/27 programmes. These domains are not in the current ColiDev allowlist. A page date does not guarantee each linked PDF is the newest edition: save its title, own date/year and checksum. / Если запускаемся по программе Узбекистана: эти официальные страницы дают правовые нормы и программы 2026/27, но их домены пока не в allowlist ColiDev. Дата страницы не гарантирует новизну каждого PDF; сохраняйте название, дату/год и checksum документа.
- [UNESCO UIS ISCED](https://uis.unesco.org/en/methods-and-tools/isced) classifies levels/fields, not lesson syllabi; [UIS API/bulk downloads](https://databrowser.uis.unesco.org/resources) and [Uzbekistan statistics](https://stat.uz/en/official-statistics/social-protection) are for education indicators, not subject facts. UIS/Stat.uz expose data API or JSON options; reviewed UZBMB curriculum pages did not show a documented API/RSS. / ISCED классифицирует уровни, а не темы уроков; UIS/Stat.uz подходят для статистики. На проверенных страницах программ UZBMB документированный API/RSS не найден.
- Check official editions, release notes/errata, publisher dates, ETag/Last-Modified and content digest. A change should open a human review task; after approval update both RU/EN lesson copies and reindex. HTTP 200 means only that the page responded. / Сверяйте редакции, errata, даты, HTTP-валидаторы и digest. Изменение запускает ручную проверку; после одобрения обновляются RU/EN и индекс. HTTP 200 подтверждает только доступность страницы.
- Reuse constraints: [OpenStax Biology 2e terms](https://openstax.org/books/biology-2e/pages/preface) say CC BY-NC-SA and prohibit LLM/generative-AI ingestion without prior written permission; check every book separately. Retain per-record GBIF attribution/licence; IUCN API is non-commercial. / Ограничения: OpenStax Biology 2e требует CC BY-NC-SA и письменное разрешение для загрузки текста в LLM/генеративный ИИ; проверяйте каждую книгу. Для GBIF сохраняйте атрибуцию/лицензию записи; IUCN API некоммерческий.

**Editorial flow / Редакторский поток:** map every lesson claim to source URL, author/publisher, exact edition, access/publisher dates, licence, last human fact-check and reviewer. The source monitor signals changes; it does not certify that a lesson is fresh or correct. / Связывайте каждое утверждение с URL, автором/издателем, редакцией, датами, лицензией, последней ручной проверкой и редактором. Монитор сообщает об изменениях, но не заверяет актуальность или точность урока.
