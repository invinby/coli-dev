### Concepts, example, and answer / Понятия, пример и ответ

**EN:** The explanation that `if` selects a branch based on a condition, `for` visits sequence items in order, and the loop variable names the current item matches the tutorial. The function’s parameter receives its argument; `return` exits the function and returns its value. For `[2, 5, 8]`, the predicate `number % 2 == 0` is true for `2` and `8`, so `count_even` returns `2`. The value `0` and negative even integers such as `-2` are also counted. An empty list leaves `count` at `0` and returns `0`. The answer key and explanation are correct.

Параметр функции получает аргумент; `return` завершает выполнение функции и возвращает значение. Для `[2, 5, 8]` условие `number % 2 == 0` истинно для `2` и `8`, поэтому `count_even` возвращает `2`. Reword both sections to say “replace the condition inside `if`” / «замени условие внутри `if`» and rename the function to `count_greater_than_10` (or an equivalent name). The required predicate `number > 10` is correct.

После изменения задачи имя `count_even` также вводит в заблуждение. Английская версия тоже не устраняет устаревшее имя функции. Само условие `number > 10` верное.

### `return`, `print`, and limits / `return`, `print` и ограничения

**EN:** `return` returns a value to the caller and ends the current function call; falling off the end of a function, or using `return` without an expression, produces `None`. `print` writes text to a stream; it does not provide the counted value as the function result. The claim is sound. The runtime visits one item per loop iteration. Calling this `O(n)` is appropriate if arithmetic/comparison cost per item is treated as constant; phrase it as “for an input of n fixed-size integers, it performs n iterations/checks, so the loop is O(n) under the usual unit-cost model.” The function does not validate the input types, which is true. For this example, state that it expects integers (or another explicitly supported numeric domain): unsupported elements can raise exceptions, and a float may satisfy the divisibility check too. The isolated-execution warning is sensible operational guidance, but it is not a Python-language claim and should not be presented as established by the Python docs.  
**RU:** `return` возвращает значение вызывающему коду и завершает текущий вызов функции; достижение конца функции без явного результата или `return` без выражения даёт `None`. `print` записывает текст в поток и не возвращает посчитанное значение как результат функции. Утверждение корректно. За один проход выполняется одна итерация для каждого элемента. Оценка `O(n)` уместна, если считать стоимость арифметики и сравнения на элемент постоянной; лучше уточнить: «для n целых чисел фиксированного размера выполняются n итераций/проверок, поэтому при стандартной модели постоянной стоимости это O(n)». Функция действительно не проверяет типы входных значений. Для этого примера нужно указать ожидаемый тип — целые числа (или явно обозначенный допустимый числовой тип): неподдерживаемые элементы могут вызвать исключение, а число с плавающей точкой также может пройти проверку делимости. Предупреждение об изолированном запуске разумно как практическая рекомендация, но это не утверждение о семантике языка и его не следует выдавать за вывод из документации Python.
