# Gemini Notebook (NotebookLM) official integration / Официальная интеграция с Gemini Notebook (NotebookLM)

**Access date / Дата проверки:** 2026-10-08
**Scope / Объём:** Official Google consumer help and Google Cloud developer documentation only. This note distinguishes documented capability from capability not documented in the official pages reviewed; it does not claim that undocumented private or future interfaces cannot exist.<br>
**Объём:** Проверены только официальная справка Google для обычного продукта и документация разработчика Google Cloud. Заметка отделяет документированные возможности от тех, которые не описаны в проверенных официальных материалах; она не утверждает, что закрытых или будущих интерфейсов не существует.

## Findings / Выводы

### Personal product: UI workflow, no consumer API documented / Личный продукт: сценарий через интерфейс, API для обычного аккаунта не документирован

**EN:** Google's consumer help currently calls the product **Gemini Notebook** (NotebookLM help remains the support destination). The official desktop workflow lets a user create a notebook and add sources in the UI. Documented inputs include local files, Google Drive files, copied text, public web URLs, and YouTube links; exact availability depends on source type and account/product limits. Google documents `.md` as a supported local source format. [Create a notebook](https://support.google.com/gemininotebook/answer/16206563?hl=en) · [Add or discover sources](https://support.google.com/gemininotebook/answer/16215270?co=GENIE.Platform%3DDesktop&hl=en)

**RU:** В актуальной потребительской справке Google продукт называется **Gemini Notebook**; раздел поддержки по-прежнему находится на домене NotebookLM. Официальный сценарий на компьютере: пользователь создаёт блокнот и добавляет источники через интерфейс. Документированы локальные файлы, файлы Google Drive, вставленный текст, публичные веб-страницы и ссылки YouTube; доступность зависит от типа источника и ограничений продукта/аккаунта. Markdown (`.md`) указан среди поддерживаемых локальных форматов. [Создание блокнота](https://support.google.com/gemininotebook/answer/16206563?hl=en) · [Добавление и поиск источников](https://support.google.com/gemininotebook/answer/16215270?co=GENIE.Platform%3DDesktop&hl=en)

**EN:** I found no official consumer REST API or SDK documentation for creating/managing personal Gemini Notebook notebooks or programmatically adding, reading, or exporting their sources. The consumer help pages reviewed describe those actions through the product UI. This is a documentation finding, not proof that no private or future API exists.

**RU:** В проверенной официальной документации не нашлось REST API или SDK для обычного Gemini Notebook, с помощью которого приложение могло бы программно создавать/вести личные блокноты, добавлять, читать или экспортировать их источники. Потребительская справка описывает эти действия через интерфейс продукта. Это вывод о доступной документации, а не доказательство отсутствия закрытого или будущего API.

### First-party UI export and synchronization / Экспорт и синхронизация через интерфейс Google

**EN:** From the UI, a user can export notes and generated reports to Google Docs, and data tables to Google Sheets. Google explicitly says edits to exported Docs/Sheets do not sync back to the notebook; sharing permissions also do not carry over. The documented UI export is therefore an artifact export, not a general notebook/source export API. [Create notebooks and export artifacts](https://support.google.com/gemininotebook/answer/16206563?hl=en) · [Export notes](https://support.google.com/gemininotebook/answer/16262519?hl=en)

**RU:** Через интерфейс Google пользователь может экспортировать заметки и созданные отчёты в Google Docs, а таблицы данных — в Google Sheets. Google прямо указывает, что изменения экспортированных документов не синхронизируются обратно в блокнот, а права доступа не переносятся. Это экспорт отдельных материалов через UI, а не универсальный API экспорта блокнота или его источников. [Блокноты и экспорт материалов](https://support.google.com/gemininotebook/answer/16206563?hl=en) · [Экспорт заметок](https://support.google.com/gemininotebook/answer/16262519?hl=en)

**EN:** A notable exception to manual refresh is Google Drive: consumer help says Drive-imported sources sync automatically every few minutes and can be synced manually when opened. The help does not promise this refresh behavior for local uploads, copied text, web URLs, or YouTube imports. [Drive and source limitations](https://support.google.com/gemininotebook/answer/16215270?co=GENIE.Platform%3DDesktop&hl=en)

**RU:** Отдельно документирована синхронизация Google Drive: импортированные оттуда источники автоматически обновляются примерно каждые несколько минут; при необходимости источник можно синхронизировать вручную при открытии. Для локальных файлов, вставленного текста, веб-ссылок и YouTube такая же автоактуализация в справке не обещана. [Drive и ограничения источников](https://support.google.com/gemininotebook/answer/16215270?co=GENIE.Platform%3DDesktop&hl=en)

### Enterprise API: official but separate and Preview / API для Enterprise: официальный, но отдельный и в Preview

**EN:** Google does document a first-party REST API for **Gemini Notebook Enterprise** (the licensing page says “NotebookLM Enterprise” was renamed; the subscription name remains NotebookLM Enterprise). The API reference is marked **Preview / Pre-GA**, uses Discovery Engine `v1alpha`, and documents notebook create/get/list-recently-viewed/delete/share plus source batch-create, file-upload, get, and batch-delete. Notebook retrieval includes source details; the documented source-get response contains identifiers, title, word/token counts, and status. The reviewed API pages do not document an endpoint to download/export the original source contents or an API for personal consumer notebooks. [Notebook API](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/api-notebooks) · [Sources API](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/api-notebooks-sources) · [Product rename and licensing](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/set-up-licensing)

**RU:** Google документирует REST API для **Gemini Notebook Enterprise** (на странице лицензирования уточнено, что NotebookLM Enterprise переименован, но название подписки осталось прежним). API помечен как **Preview / Pre-GA**, использует Discovery Engine `v1alpha` и документирует создание, чтение, список недавно открытых, удаление и совместный доступ к блокнотам, а также пакетное добавление источников, загрузку файла, чтение метаданных источника и пакетное удаление. Чтение блокнота возвращает сведения об источниках; описанный ответ чтения источника содержит идентификаторы, заголовок, число слов/токенов и статус. В проверенных API-страницах не описана загрузка/экспорт исходного содержимого источника или API для личного потребительского аккаунта. [API блокнотов](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/api-notebooks) · [API источников](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/api-notebooks-sources) · [Переименование и лицензирование](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/set-up-licensing)

**EN:** Enterprise API use requires an Enterprise setup, Google Cloud project, IAM access (including the Cloud NotebookLM User role for users), and a license/subscription for the applicable multi-region. Google warns Preview features are pre-GA, may have limited support, and are provided as-is. Enterprise imports are described as static source copies; do not assume consumer Drive auto-sync applies to the Enterprise API. [Enterprise overview and product boundary](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/overview) · [API Preview terms](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/api-notebooks) · [Licenses](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/set-up-licensing)

**RU:** Для Enterprise API нужны настройка Enterprise, проект Google Cloud, IAM-доступ (включая роль Cloud NotebookLM User для пользователей) и лицензия/подписка в нужном мульти-регионе. Google предупреждает, что Preview-функции относятся к Pre-GA, могут иметь ограниченную поддержку и предоставляются «как есть». Для Enterprise импорт описан как создание статической копии источника; нельзя автоматически переносить на этот API синхронизацию Drive, описанную для потребительского интерфейса. [Обзор Enterprise и границы продукта](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/overview) · [Условия Preview API](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/api-notebooks) · [Лицензии](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/set-up-licensing)

## Product decision for ColiDev / Решение для ColiDev

**EN:** For personal accounts and a no-paid-Enterprise assumption, keep the supported user-mediated path: export a ColiDev lesson as `.md`, let the user import it in Gemini Notebook, and open the official site from the app. If a later product requirement justifies Enterprise, evaluate its REST API behind explicit Google Cloud sign-in, project/region configuration, license checks, and clear source-transfer consent. Do not label either path “automatic two-way sync.”

**RU:** Для личных аккаунтов и при отсутствии бюджета на Enterprise оставляем поддерживаемый сценарий с участием пользователя: экспортировать урок ColiDev в `.md`, импортировать его в Gemini Notebook вручную и дать кнопку открыть официальный сайт. Если позже появится обоснование для Enterprise, отдельно оценить REST API с авторизацией Google Cloud, настройкой проекта/региона, проверкой лицензии и явным согласием на передачу источников. Ни один из этих сценариев не следует называть «автоматической двусторонней синхронизацией».

## Evidence boundary / Граница доказательств

**EN:** Checked official pages linked above on 2026-10-08. “Not documented” means no consumer API/export operation was found in those official product/developer references; it does not rule out undocumented private interfaces or later product changes. No API calls, account access, or product UI import/export were performed as part of this research.

**RU:** Официальные страницы по ссылкам выше проверены 2026-10-08. Формулировка «не документировано» означает, что в этих официальных пользовательских и developer-материалах не нашлись соответствующий consumer API или операция экспорта; она не исключает закрытые интерфейсы и будущие изменения продукта. В рамках исследования не выполнялись API-вызовы, вход в аккаунт или реальный импорт/экспорт через интерфейс.
