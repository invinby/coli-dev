## Начатый SwiftUI-клиент

`macOS/ColiDev/` содержит ранний Xcode-проект: локальный RU/EN-каталог шести предметов, учебные экраны, стартовые практики и десять отдельно написанных RU/EN-модулей: по одному для каждого направления и по одному дополнительному модулю для математики, английского, физики и биологии. Новый английский intermediate-урок сопоставляет Present Perfect Simple и Continuous; нативный тренажёр даёт сценарии на количество, длительность и глаголы состояния. Новые модули доступны офлайн из Markdown внутри app bundle; каждый включает цель, теорию, практику, варианты ответа, правильный ответ с разбором, границы вывода и ссылки на источники. Перед завершением требуется правильный ответ и подтверждение ученика.

Это не законченный продукт: подключён RU/EN-чат с существующим FastAPI-оркестратором на localhost; реальное переключение локального/облачного маршрута на пользовательском Mac ещё не проверено запуском. Есть retrieval из подключённого Obsidian vault и постоянный SQLite-индекс Markdown-курсов. Индекс обновляет изменённые файлы, ищет без сети и возвращает цитаты, путь, строки, время получения и файловую дату изменения. Эта дата не подтверждает свежесть или точность фактов; у Obsidian дата изменения пока неизвестна. По умолчанию индекс использует лексический BM25-подобный поиск; необязательные локальные Ollama embeddings включаются через `OLLAMA_EMBEDDING_MODEL`, дополняют лексическое ранжирование и откатываются к нему при сбое. Код семантического пути прошёл mock-тесты, но работа с настоящей установленной моделью ещё не проверена; commit `b8f5cb4` прошёл 100 локальных backend-тестов и GitHub Actions. Commit `ddd87c5` прошёл сборку и bundle-check шести curriculum-файлов (run 37242014526); commit `ca41210` прошёл повторные backend checks, macOS build и bundle-check (run 37242458691). Commit `112ec62` с вращаемой SceneKit-визуализацией силы/массы прошёл backend checks и macOS build (run 37243523767). Полный набор 3D-симуляций не готов. Ранее UI подтверждался CI-сборкой; снимки пользователя от 2026-10-05 теперь подтверждают запуск окна на Mac, но не приёмку всех пользовательских сценариев. В Auto есть отдельный добровольный Google Search grounding: по умолчанию он отправляет только вопрос и контекст урока, без локального RAG; второй выключенный по умолчанию opt-in может добавить до четырёх фрагментов курса/Obsidian в тот же Gemini-запрос. Оба маршрута минуют агентный спор и не сохраняют ответ в Obsidian. Для отправки требуется подтверждение 18+, однако это не проверка возраста и не готовое ограничение аудитории для релиза. Это ещё не полный web-RAG с политикой надёжных источников и управляемым обновлением. Расширенные курсы и авторское наполнение, проверка авторитетности источников, полноценные 3D-симуляции, видеокаталог, синхронизация и полные интеграции ещё впереди.

Ключи Gemini, Kimi и Obsidian теперь можно ввести в SwiftUI-настройках: backend сохраняет их через `keyring.backends.macOS.Keyring`, а UI получает только источник и признак наличия. API отклоняет запросы не с loopback и чужой браузерный Origin; `.env` остаётся fallback. `Local-only` принимает Ollama только на localhost/loopback через отдельный HTTP-клиент без системных proxy; удалённый адрес блокируется до HTTP-вызова. Obsidian тоже ограничен loopback, удалённый REST endpoint не получает ключ или поисковый запрос. `/health` сообщает статус, а UI предупреждает и выключает неподтверждённый Local-only маршрут. CI run 37238373761 подтвердил базовый commit `18c98a5`; после добавления шести дорожных карт локально прошло 95 тестов, затем CI run 37239594309 успешно выполнил backend-проверки и сборку на GitHub-hosted macOS 15 / Xcode 16.4 для commit `325e74b`. Реальное чтение/запись пользовательского Keychain, живой Gemini grounding и работа Ollama на Mac пока не проверены; снимки подтверждают запуск окна, но не эти интеграции и не полный пользовательский сценарий.

### Официальные первоисточники в RAG-карточках

Учебный индекс сохраняет рядом с каждым Markdown-уроком список canonical title/URL только для четырёх утверждённых HTTPS-доменов. Данные мигрируют в уже существующей SQLite базе с пустым списком по умолчанию; обновляются вместе с файлом при индексировании. `/chat/stream` передаёт их вместе с `[K#]`-ссылкой модели и в SSE-метаданных, а SwiftUI показывает проверяемые внешние ссылки с повторной проверкой схемы и точного host. Чужие URL не передаются модели как первоисточники и не становятся ссылками в UI. Это provenance для локального урока, не загрузка страницы, не независимый фактчекинг и не полноценный web-RAG. macOS-сборка SwiftUI-части этого изменения всё ещё требует Xcode CI.

Для commit `fbf18e5` локально пройдены 295 backend-тестов и Ruff/compileall. GitHub Actions run [37311093375](https://github.com/invinby/coli-dev/actions/runs/37311093375) завершил все три jobs без единого шага и без доступных логов; этот запуск не подтвердил backend CI или Xcode-сборку. Причина отказа в данных run не раскрыта. Текущий код требует успешной CI-сборки и запуска SwiftUI на Mac перед заявлением о готовности.

В текущем срезе проверки источников есть обратно-совместимая миграция SQLite: для каждой разрешённой страницы сохраняются только заголовок, краткое описание, SHA-256 нормализованного текста и дата проверки. До 512 KiB HTML читается только в памяти, редиректы запрещены; полный текст не хранится и не индексируется. Панель Sources показывает эти метаданные отдельно от редакторской даты урока и HTTP Last-Modified, ищет по названию источника, URL, предмету и пути урока, фильтрует очередь проверки. Контентные/HTTP изменения, первая baseline-проверка старой записи и непригодные ответы требуют внимания редактора; сама проверка не переписывает урок и не подтверждает факты. Это изменение ещё требует backend CI, SwiftUI-сборки и запуска на Mac; локальные тесты в этой итерации не запускались.

## Текущий инкремент — связанные уроки и повторение (2026-10-05)

- Каждая из шести приоритетных дорожных карт ссылается минимум на один доступный двуязычный модуль; математика включает функции и область определения/значений, физика — равнодействующую силу и кинетическую энергию, биология — осмос и наследование одного гена. SwiftUI открывает их по slug из bundle; проверка slug не позволяет строить произвольный путь.
- Контент одновременно остаётся в разрешённом локальном индексе RAG; backend-тесты подтверждают, что тематический RU/EN-запрос первым находит нужный урок.
- Уроки содержат предметные тренажёры, MC-проверку с двуязычными вариантами и разбором после правильного ответа. Событие завершения/review использует lesson ID, выбранная оценка вспоминания передаётся локальному SQLite-планировщику.
- Chat API принимает фиксированный предметный код и добавляет подходящую RU/EN проверочную рубрику для математики, английского, физики, биологии, зоологии или программирования. Рубрика доходит до всех ролей Auto, локального тьютора и отдельного Google-grounded пути; клиенты без предметного поля остаются совместимы. В текущей рабочей копии Control Center теперь позволяет назначить провайдера и model ID слоту специалиста Auto для каждого из шести предметов; ключи не копируются в route-файл, ошибка возвращает запрос к общему маршруту. Полная per-agent настройка ещё не сделана.

## Session state resilience — 2026-10-05

Файл квоты/режима сессий теперь загружается с проверкой схемы и размера; повреждённые записи сбрасываются безопасно. Запись идёт во временный файл с `fsync` и атомарным `replace`, чтобы прерванная операция не затёрла прежнее состояние. Unit-тесты передают временный путь вместо пользовательского app-data файла.

## Request body limits — 2026-10-05

ASGI middleware ограничивает запросы размером 1 MiB до разбора JSON, включая chunked body, и проверяет согласованность `Content-Length`. Для tutor prompt/context и Obsidian write/search установлены отдельные максимумы; чрезмерный HTTP body возвращает 413, некорректный `Content-Length` — 400.

Локальный полный backend suite: 175 passed; `compileall` и `git diff --check` прошли. GitHub Actions run [37253856279](https://github.com/invinby/coli-dev/actions/runs/37253856279) успешно выполнил backend checks, macOS build и bundle-check.

## Автоматическая и ручная проверка ссылок на источники — 2026-10-06

Пока локальный backend ColiDev работает, фоновый планировщик проверяет ссылки из встроенных `02_Areas/**/lessons/*.md` не чаще раза в 24 часа; временные ошибки сети повторяются через шесть часов. Кнопка раздела «Центр управления» по-прежнему запускает немедленную loopback-only `POST /knowledge/sources/check`. Монитор принимает только точные HTTPS-ссылки на страницы четырёх фиксированных доменов: OpenStax, Python docs, British Council LearnEnglish и Animal Diversity Web. Произвольный URL пользователь передать не может; HTTP-клиент не использует системный proxy, ограничивает параллелизм, таймаут и пакет из 20 ссылок, а редиректы не следуют. Неподдерживаемые и пропущенные по лимиту ссылки показываются отдельно. Для доступных страниц SQLite хранит ETag/Last-Modified, заголовок/описание, SHA-256 отпечаток нормализованного текста и дату проверки. Полный текст страницы не сохраняется и не попадает в RAG; обнаруженное изменение отмечается редактору, но не переписывает уроки автоматически. Статус не подтверждает качество источника или свежесть конкретного факта. Автопроверка не работает, когда локальный backend закрыт.

`GET /knowledge/sources` объединяет один canonical URL со всеми уроками, где он указан, и возвращает отдельные `source_checked`, интервал и расчётную дату следующей редакторской проверки для каждой связи «источник—урок». Сводка различает просроченные, запланированные, без даты и без графика. Для всех 10 текущих уроков заданы интервалы: программирование — 90 дней, английский/биология/зоология — 180, математика/физика — 365. Это операционные напоминания; они не подтверждают свежесть фактов.

В `main` добавлен RU/EN SwiftUI Control Center с разделами «Обзор», «Источники» и «Сервисы» (commit `a322afe`). Он читает `GET /knowledge/sources` без сетевой проверки, показывает URL, связанный урок, `source_checked` как дату редакторской проверки отдельно от технической проверки URL и HTTP `Last-Modified`, а также вызывает существующие проверку ссылок и обновление локального индекса. ## Состояние интеграции AI

Нативный клиент вызывает GET /health и POST /chat/stream на localhost. Язык ответа передаётся явно (ru/en), а старые API-клиенты сохраняют русский язык по умолчанию. Обычный Auto-запрос использует локальный индекс и Obsidian; найденные выдержки передаются как JSON-данные в сообщении ученика, отдельно от system prompt. Gemini получает system instruction и user content раздельно; в system instruction сказано считать выдержки недоверенными данными и не выполнять инструкции внутри них. Это снижает риск prompt injection, но не гарантирует безошибочное поведение модели. При разрешённой отправке фрагменты могут уйти настроенным облачным моделям. Отдельный opt-in Google Search отвечает на текущий вопрос с контекстом урока, ссылками на источники и Search Suggestions; по умолчанию не вызывает local retrieval, другие агенты и Obsidian save. Второй отдельный opt-in добавляет в этот запрос до четырёх совпавших выдержек курса/Obsidian; интерфейс предупреждает об отправке этих локальных данных в Google. Каждый доступный нативный урок можно сохранить как локальный Markdown-файл для ручного импорта в NotebookLM; автоимпорта и синхронизации нет. Экспорт собран и проверен в CI run [37262635710](https://github.com/invinby/coli-dev/actions/runs/37262635710) для Apple Silicon и Intel; реальный импорт в аккаунт NotebookLM не проверен. SSE начинает HTTP-ответ до локального retrieval/генерации, а отключение клиента отменяет in-flight async работу; текст модели пока буферизуется до выдачи чанками. Этот lifecycle прошёл 194 локальных теста и CI run [37263464753](https://github.com/invinby/coli-dev/actions/runs/37263464753) на backend и двух macOS-сборках. Тесты используют моки; live Gemini, Keychain пользователя, Ollama/Obsidian, NotebookLM и запуск `.app` не проверены. Полный web-RAG, видео, синхронизация и настоящий 3D не подключены. Удалён wildcard CORS, но полный аудит безопасности API остаётся отдельной задачей.

## Предпросмотр официального источника из Control Center — 2026-10-06

Реестр источников получил RU/EN кнопку предпросмотра. Она отправляет URL localhost-backend; backend принимает его только при точном совпадении с уже разрешённой ссылкой из встроенного урока, скачивает только HTTPS HTML с allowlist домена/пути, не следует редиректам и не использует proxy. Входной HTML ограничен 512 KiB, UI получает максимум 8 000 символов извлечённого видимого текста, название страницы, URL, связанные уроки, краткое описание и время получения. Сам предпросмотр не сохраняет страницу и не добавляет текст в локальный RAG. Из sheet можно подтвердить, что конкретный урок соответствует увиденной редакции источника: backend снова получает страницу, сверяет SHA-256 отпечаток с показанным preview и при совпадении сохраняет дату/отпечаток и событие в локальной SQLite-истории с ограничением в 10 000 последних записей. Изменившийся после preview источник отклоняется; новая проверка монитора инвалидирует старую редакторскую отметку при несовпадении digest. Полный просмотр истории, редакция уроков и ingestion web-фрагментов пока не реализованы.
