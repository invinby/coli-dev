# 02. Текущее состояние ColiDev

## Подтверждено чтением текущего репозитория

- Python-проект с FastAPI и оркестратором ИИ-запросов.
- В README описаны отдельные режимы с облачными моделями, консилиумом и локальным режимом.
- Есть веб-интерфейс/API чата, потоковая выдача, проверка здоровья и статуса.
- Есть маршруты и worker для работы с Obsidian.
- Есть учебные заметки по Python/backend и соседним темам.
- Корень проекта уже привязан к приватному GitHub-репозиторию `invinby/coli-dev`; ветка `main` отслеживает `origin/main`.

## Начатый SwiftUI-клиент

`macOS/ColiDev/` содержит ранний Xcode-проект: локальный RU/EN-каталог шести предметов, учебные экраны, стартовые практики и шесть отдельно написанных RU/EN-модулей, связанных с темами дорожных карт. Новые модули доступны офлайн из Markdown внутри app bundle; каждый включает цель, теорию, практику, варианты ответа, правильный ответ с разбором, границы вывода и ссылки на источники. Перед завершением требуется правильный ответ и подтверждение ученика.

Это не законченный продукт: подключён RU/EN-чат с существующим FastAPI-оркестратором на localhost; реальное переключение локального/облачного маршрута на пользовательском Mac ещё не проверено запуском. Есть retrieval из подключённого Obsidian vault и постоянный SQLite-индекс Markdown-курсов. Индекс обновляет изменённые файлы, ищет без сети и возвращает цитаты, путь, строки, время получения и файловую дату изменения. Эта дата не подтверждает свежесть или точность фактов; у Obsidian дата изменения пока неизвестна. По умолчанию индекс использует лексический BM25-подобный поиск; необязательные локальные Ollama embeddings включаются через `OLLAMA_EMBEDDING_MODEL`, дополняют лексическое ранжирование и откатываются к нему при сбое. Код семантического пути прошёл mock-тесты, но работа с настоящей установленной моделью ещё не проверена; commit `b8f5cb4` прошёл 100 локальных backend-тестов и GitHub Actions. Commit `ddd87c5` прошёл сборку и bundle-check шести curriculum-файлов (run 37242014526); commit `ca41210` прошёл повторные backend checks, macOS build и bundle-check (run 37242458691). Commit `112ec62` с вращаемой SceneKit-визуализацией силы/массы прошёл backend checks и macOS build (run 37243523767). Полный набор 3D-симуляций не готов. UI проверен CI-сборкой, а не запуском на Mac. В Auto добавлен отдельный добровольный прямой Google Search grounding: Gemini возвращает ответ с inline-цитатами и обязательным Search Suggestions; этот маршрут не использует локальный RAG, агентный спор или сохранение в Obsidian. Для отправки требуется подтверждение 18+, однако это не проверка возраста и не готовое ограничение аудитории для релиза. Это ещё не полный web-RAG с политикой надёжных источников и управляемым обновлением. Расширенные курсы и авторское наполнение, проверка авторитетности источников, полноценные 3D-симуляции, видеокаталог, синхронизация и полные интеграции ещё впереди.

Ключи Gemini, Kimi и Obsidian теперь можно ввести в SwiftUI-настройках: backend сохраняет их через `keyring.backends.macOS.Keyring`, а UI получает только источник и признак наличия. API отклоняет запросы не с loopback и чужой браузерный Origin; `.env` остаётся fallback. `Local-only` принимает Ollama только на localhost/loopback через отдельный HTTP-клиент без системных proxy; удалённый адрес блокируется до HTTP-вызова. Obsidian тоже ограничен loopback, удалённый REST endpoint не получает ключ или поисковый запрос. `/health` сообщает статус, а UI предупреждает и выключает неподтверждённый Local-only маршрут. CI run 37238373761 подтвердил базовый commit `18c98a5`; после добавления шести дорожных карт локально прошло 95 тестов, затем CI run 37239594309 успешно выполнил backend-проверки и сборку на GitHub-hosted macOS 15 / Xcode 16.4 для commit `325e74b`. Реальное чтение/запись пользовательского Keychain, живой Gemini grounding, Ollama на Mac и запуск приложения пока не проверены.

## Текущий инкремент — связанные уроки и повторение (2026-10-05)

- Каждая из шести приоритетных дорожных карт теперь ссылается на один доступный двуязычный модуль. SwiftUI открывает его по slug из bundle; проверка slug не позволяет строить произвольный путь.
- Контент одновременно остаётся в разрешённом локальном индексе RAG; backend-тесты подтверждают, что тематический RU/EN-запрос первым находит нужный урок.
- Уроки содержат предметные тренажёры, MC-проверку с двуязычными вариантами и разбором после правильного ответа. Событие завершения/review использует lesson ID, выбранная оценка вспоминания передаётся локальному SQLite-планировщику.
- Commit `e5ec472` запушен в `main`. GitHub Actions run [37249729913](https://github.com/invinby/coli-dev/actions/runs/37249729913) успешно выполнил backend suite и macOS 15/Xcode build, затем проверил curriculum и все шесть новых lesson-файлов в bundle. Локально `pytest 01_Projects -q` — 117 passed, одно предупреждение Starlette/httpx; `compileall`, проверка 80 строковых ключей и `git diff --check` прошли. Ручного запуска приложения на Mac по-прежнему не было.
- Это по одному содержательному примеру на предмет, а не полная программа. Живые провайдеры, ручной запуск на Mac, экспертная редактура всех курсов и остальные продуктовые интеграции остаются непроверенными/незавершёнными.
- Индекс и источник теперь различают файловый `modified_at` и авторский `source_checked_at` из Markdown frontmatter; заголовок убирается из RAG-выдержек, а исходные номера строк сохраняются. В prompt/UI есть оговорка: проверка списка ссылок не доказывает актуальность фактов. Commit `304717a`; run [37250882001](https://github.com/invinby/coli-dev/actions/runs/37250882001) зелёный по backend suite, macOS build и bundle-check. Локально прошло 121 тест; фактическая свежесть внешних источников не автоматизирована.

## Backend API guard — 2026-10-05

Loopback и Origin проверки распространены на health/status, сессии, tutor chat и все Obsidian-маршруты; настройки провайдеров и учебный прогресс уже используют ту же проверку. Тесты проверяют блокировку чужого Origin и удалённого клиента до обращения к локальным данным или провайдерам. Полный security-аудит остаётся открытым; сам сервер по-прежнему не имеет пользовательской аутентификации.

Commit `aac9cb9` запушен в `main`; GitHub Actions run [37251653614](https://github.com/invinby/coli-dev/actions/runs/37251653614) прошёл backend checks и macOS build/bundle-check. Локально полный suite прошёл: 137 тестов.

## OS-aware storage paths — 2026-10-05

Backend использует per-user пути ОС для индекса, состояния сессий, прогресса и логов; `COLIDEV_DATA_DIR` и `COLIDEV_LOG_DIR` позволяют задать отдельные директории. Существующие SQLite прогресса и JSON-сессий в прежних путях остаются доступны, пока новая база/файл не появятся. Windows больше не пишет логи и сессии в macOS-папку `~/Library`.

Commit `a8b7320`; run [37252284801](https://github.com/invinby/coli-dev/actions/runs/37252284801) прошёл backend checks и macOS build/bundle-check. Полный локальный backend suite: 143 passed.

## Obsidian bridge hardening — 2026-10-05

Obsidian worker сам отвергает удалённые target URL до отправки Bearer token; перед построением endpoint проверяются и URL-кодируются vault-relative пути. Абсолютные пути, traversal, закодированные `..`, контрольные символы и чрезмерно длинные пути блокируются; API возвращает 422 на неверный путь. Commit `e1ee8db`; GitHub Actions run [37252817814](https://github.com/invinby/coli-dev/actions/runs/37252817814) прошёл backend checks и macOS build/bundle-check. Локальный backend suite: 160 тестов.

## Session state resilience — 2026-10-05

Файл квоты/режима сессий теперь загружается с проверкой схемы и размера; повреждённые записи сбрасываются безопасно. Запись идёт во временный файл с `fsync` и атомарным `replace`, чтобы прерванная операция не затёрла прежнее состояние. Unit-тесты передают временный путь вместо пользовательского app-data файла.

Полный локальный backend suite: 165 passed; `compileall` и `git diff --check` прошли. Commit `b5fc09c`; GitHub Actions run [37253372336](https://github.com/invinby/coli-dev/actions/runs/37253372336) успешно прошёл backend checks и macOS build/bundle-check.

## Request body limits — 2026-10-05

ASGI middleware ограничивает запросы размером 1 MiB до разбора JSON, включая chunked body, и проверяет согласованность `Content-Length`. Для tutor prompt/context и Obsidian write/search установлены отдельные максимумы; чрезмерный HTTP body возвращает 413, некорректный `Content-Length` — 400.

Локальный полный backend suite: 175 passed; `compileall` и `git diff --check` прошли. GitHub Actions run [37253856279](https://github.com/invinby/coli-dev/actions/runs/37253856279) успешно выполнил backend checks, macOS build и bundle-check.

## Напоминания о перепроверке источников RAG по графику автора — 2026-10-05

В Markdown frontmatter можно указать `source_checked` и `source_review_interval_days` (1–3650). Индекс мигрирует nullable-колонку в существующей SQLite базе и возвращает дату/статус авторского напоминания. RU/EN-карточка источника и prompt называют это напоминанием, а не автоматической проверкой актуальности фактов. Источники извне не загружаются и не проверяются.

Полный локальный backend suite прошёл: 177 тестов и одно известное предупреждение Starlette/httpx; `compileall` и `git diff --check` прошли. GitHub Actions run [37254689783](https://github.com/invinby/coli-dev/actions/runs/37254689783) успешно выполнил backend checks, сборку macOS и bundle-check. Приложение вручную на Mac не запускалось.

## Backend внутри `.app` и ручное обновление локального индекса — 2026-10-05

CI собирает отдельный PyInstaller runtime под arm64 и Intel, помещает его внутрь `ColiDev.app`, запускает API smoke-check и проверяет страницы курса в bundle. `LocalBackendSupervisor` запускает дочерний сервис при открытии клиента и останавливает его при завершении приложения. Новый раздел настроек запускает `POST /knowledge/refresh`: backend безопасно обновляет индекс встроенных учебных Markdown-файлов без вызова embeddings/провайдера, возвращает число документов и дату сканирования. Endpoint доступен только loopback-запросу с разрешённым Origin. Этот контроль не загружает интернет-материалы и не оценивает их фактическую свежесть.

Commit `d5f1d6e` запушен в `main`; GitHub Actions run [37257110910](https://github.com/invinby/coli-dev/actions/runs/37257110910) успешно выполнил 180 backend-тестов, собрал приложения и проверил встроенный runtime на Apple Silicon и Intel. Smoke-check запускает API из ресурсов `.app`, но не открывает сам SwiftUI-интерфейс. Полный локальный прогон перед последним API error-case тестом: 179 passed; после него целевые тесты индекса/API: 46 passed. Осталось предупреждение Starlette/httpx. Настоящий запуск SwiftUI-клиента на Mac пользователя и реальные провайдеры не проверены.

## Не подтверждено запуском

### OpenRouter как резервный cloud specialist — 2026-10-05

В рабочей копии добавлена опциональная цепочка Kimi → OpenRouter: OpenRouter используется, когда ключ Kimi отсутствует или запрос Kimi завершается ошибкой; по умолчанию настроен маршрут `openrouter/free`. API key сохраняется через существующий Keychain endpoint, а Settings показывает настроенный маршрут и предупреждает про меняющиеся лимиты/возможную оплату. Запрос идёт только на фиксированный официальный OpenRouter endpoint. Ошибки провайдера не копируют тело HTTP-ответа в лог, а некорректный Kimi-ответ переводит цепочку на fallback. Gemini остаётся обязательным главным судьёй Auto-режима; OpenRouter сам по себе не делает приложение полностью работоспособным без Gemini.

Полный backend suite для этого этапа: 185 тестов в commit `26c2c5e`; GitHub Actions run [37258691883](https://github.com/invinby/coli-dev/actions/runs/37258691883) успешно выполнил backend-тесты, собрал `.app` и проверил встроенный backend для Apple Silicon и Intel. CI не открывает GUI. Последующее изменение сообщает в подписи ответа model ID из ответа OpenRouter, а если поля нет — сообщает только настроенный маршрут; текущая рабочая копия прошла 191 backend-тест. CI этого дополнительного изменения ещё ожидается. Запуск SwiftUI на Mac и живой ключ/ответ OpenRouter остаются непроверенными; сообщённый API model ID не является независимой проверкой фактической инфраструктуры провайдера.

CI run [37258944995](https://github.com/invinby/coli-dev/actions/runs/37258944995) выявил хрупкость smoke-скрипта на Intel: `grep -q` закрывал `curl` pipe после совпадения, а `pipefail` трактовал это как сбой записи. Скрипт переведён на загрузку страницы во временный файл перед поиском; исправление ждёт повторного macOS CI.

- Полная работоспособность всех режимов и провайдеров.

- Запуск SwiftUI-интерфейса на настоящем Mac с проверкой интерактивных экранов.

## Состояние интеграции AI

Нативный клиент вызывает GET /health и POST /chat/stream на localhost. Язык ответа передаётся явно (ru/en), а старые API-клиенты сохраняют русский язык по умолчанию. Обычный Auto-запрос использует локальный индекс и Obsidian; при разрешённой отправке найденные фрагменты могут уйти настроенным облачным моделям. Отдельный opt-in Google Search отвечает только на текущий вопрос с контекстом урока, ссылками на источники и Search Suggestions; он не вызывает local retrieval, другие агенты и Obsidian save. CI run 37234161777 прошёл для commit `1698e11` (loopback-защита), а run 37238373761 — для `18c98a5` (Google Search grounding); оба включали backend suite и сборку на GitHub-hosted macOS 15 / Xcode 16.4. Текущий локальный прогон после добавления шести дорожных карт прошёл 95 тестов; свежая CI-проверка этих изменений ожидает push. Тесты используют моки; live Gemini, Keychain пользователя, Ollama/Obsidian и запуск `.app` не проверены. Полный web-RAG, NotebookLM, видео, синхронизация и настоящий 3D не подключены. Удалён wildcard CORS, но полный аудит безопасности API остаётся отдельной задачей.
