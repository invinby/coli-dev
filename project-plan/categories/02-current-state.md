# 02. Текущее состояние ColiDev

## Подтверждено чтением текущего репозитория

- Python-проект с FastAPI и оркестратором ИИ-запросов.
- В README описаны отдельные режимы с облачными моделями, консилиумом и локальным режимом.
- Есть веб-интерфейс/API чата, потоковая выдача, проверка здоровья и статуса.
- Есть маршруты и worker для работы с Obsidian.
- Есть учебные заметки по Python/backend и соседним темам.
- Корень проекта уже привязан к приватному GitHub-репозиторию `invinby/coli-dev`; ветка `main` отслеживает `origin/main`.

## Начатый SwiftUI-клиент

`macOS/ColiDev/` содержит ранний Xcode-проект: локальный RU/EN-каталог шести предметов, отдельный учебный экран, интерактивный 2D-блок по каждому предмету, вопрос с обратной связью и сохранение языка/завершения уроков в локальных настройках macOS.

Это не законченный продукт: подключён RU/EN-чат с существующим FastAPI-оркестратором на localhost; его реальное переключение локального/облачного маршрута ещё не проверено запуском. Добавлен retrieval из подключённого Obsidian vault и постоянный SQLite-индекс Markdown-курсов. Индекс обновляет изменённые файлы, ищет без сети и возвращает цитаты, путь, строки, время получения и файловую дату изменения. Эта дата не подтверждает свежесть или точность фактов; у Obsidian дата изменения пока неизвестна. Индекс использует лексический BM25-подобный поиск, без семантических эмбеддингов и веб-источников. Расширенные курсы и авторское наполнение, проверка авторитетности источников, web-RAG, настоящий 3D, видеокаталог, синхронизация и полные интеграции ещё впереди.

Ключи Gemini, Kimi и Obsidian теперь можно ввести в SwiftUI-настройках: backend сохраняет их через `keyring.backends.macOS.Keyring`, а UI получает только источник и признак наличия. API отклоняет запросы не с loopback и чужой браузерный Origin; `.env` остаётся fallback. Чистый Windows test-venv прошёл 55 backend-тестов с пустыми переменными провайдеров; сборка SwiftUI и импорт macOS Keychain backend на GitHub Actions для этого изменения ещё ожидаются.

## Не подтверждено запуском

- Полная работоспособность всех режимов и провайдеров.
- Актуальность названий моделей и совместимость каждого API.
- Поведение на Mac и установка приложения как самостоятельного `.app`.
- Восстановление с нуля по README на чистой машине.
- Интерактивный запуск приложения на пользовательском Mac и установка готового `.app`.

## Состояние интеграции AI

Нативный клиент вызывает GET /health и POST /chat/stream на localhost. Язык ответа передаётся явно (ru/en), а старые API-клиенты сохраняют русский язык по умолчанию. Контекст урока, короткая история диалога и отдельный поисковый запрос отправляются оркестратору. Backend параллельно обновляет/ищет локальный индекс и запрашивает Obsidian, затем перемешивает до четырёх источников, добавляет маркеры и возвращает метаданные в SSE-событии завершения. Health сообщает число локальных документов и время последней проверки; SwiftUI показывает это в настройках. В автоматическом режиме вопрос и найденные фрагменты курсов/Obsidian могут отправляться настроенным облачным моделям; это раскрыто в интерфейсе. GitHub Actions run 37230168823 прошёл: 48 backend-тестов и сборка на macOS 15 / Xcode 16.4 успешны. Тесты используют моки провайдеров и временный файл сессий; реальный запуск приложения на пользовательском Mac и запросы к провайдерам, Obsidian и Ollama всё ещё не проверены. Широкий проверенный web-RAG, NotebookLM, видео, синхронизация и настоящий 3D не подключены. Удалён wildcard CORS, но полный аудит безопасности API остаётся отдельной задачей.

4. Зафиксировать ограничения сборки и запуска на целевой платформе.
