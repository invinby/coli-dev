# 02. Текущее состояние ColiDev

## Подтверждено чтением текущего репозитория

- Python-проект с FastAPI и оркестратором ИИ-запросов.
- В README описаны отдельные режимы с облачными моделями, консилиумом и локальным режимом.
- Есть веб-интерфейс/API чата, потоковая выдача, проверка здоровья и статуса.
- Есть маршруты и worker для работы с Obsidian.
- Есть учебные заметки по Python/backend и соседним темам.
- Корень проекта уже привязан к приватному GitHub-репозиторию `invinby/coli-dev`; ветка `main` отслеживает `origin/main`.

## Не подтверждено запуском

- Полная работоспособность всех режимов и провайдеров.
- Актуальность названий моделей и совместимость каждого API.
- Поведение на Mac и установка приложения как самостоятельного `.app`.
- Восстановление с нуля по README на чистой машине.

## Отличие от второго направления

В присланной концепции описан более широкий учебный тьютор: курсы, механизм обучения, тесты, повторение, визуализации и видео. В этой папке репозитория отдельного SwiftUI-приложения не найдено; код второго продукта здесь пока не объединён.

## Следующие задачи аудита

1. Составить карту текущих экранов, API, провайдеров, хранения истории и учебного контента.
2. Отделить рабочие функции от устаревших/задуманных по документации.
3. Проверить безопасность API-маршрутов и конфигурацию секретов перед расширением.
4. Зафиксировать ограничения сборки и запуска на целевой платформе.
