# 📚 02_Areas — Учебные материалы ColiDev

Здесь хранятся локальные учебные источники, которые индексируются для офлайн-RAG. Старые материалы Python/backend сохранены; новые направления добавлены отдельными папками.

## Приоритетные дорожные карты

- [Математика](Mathematics/curriculum.md)
- [Английский язык](English/curriculum.md)
- [Физика](Physics/curriculum.md)
- [Биология](Biology/curriculum.md)
- [Зоология](Zoology/curriculum.md)
- [Программирование](Programming/curriculum.md)

Эти шесть файлов задают последовательность от базовых к углублённым темам и идеи практики. Это пока карты покрытия, а не готовые проверенные курсы; подробные уроки, источники и задания нужно добавлять отдельными этапами.

## Существующий трек Python/backend

- **Syntax_and_OOP/** — основы Python, синтаксис и объектная модель
- **Databases_SQL/** — PostgreSQL, SQL и SQLAlchemy
- **Django_FastAPI/** — Django, FastAPI и REST API
