# Линейные уравнения: сохраняем равенство / Linear Equations: Keep Both Sides Equal

## Русский

### Цель

Решить уравнение вида `ax + b = c`, применяя одинаковые обратные операции к обеим сторонам, а затем проверить ответ подстановкой.

### Идея и механизм

Знак равенства означает, что значения слева и справа одинаковы. Если к обеим сторонам прибавить или из обеих сторон вычесть одно и то же число, равенство сохранится. Так же работает деление обеих сторон на одно и то же ненулевое число.

Пример: `3x − 5 = 16`. Прибавим `5` к обеим сторонам: `3x = 21`. Разделим обе стороны на `3`: `x = 7`. Здесь мы не «перенесли» `−5` через знак равенства как отдельное правило: мы выполнили одну и ту же операцию с обеими сторонами.

Проверка: подставим `x = 7` в исходное равенство. Слева `3 × 7 − 5 = 16`, справа тоже `16`, значит ответ подходит.

### Исследуй и потренируйся

В тренажёре сначала убери постоянное слагаемое одинаковым действием с обеих сторон, затем раздели обе стороны на коэффициент при `x`. После этого подставь найденное значение в исходное равенство. В каждом новом примере меняются коэффициент, решение и постоянное слагаемое.

### Вопрос

Реши `4x + 3 = 19`. Какое значение `x` удовлетворяет равенству?

### Варианты

- `3`
- `4`
- `5`

### Ответ

2

### Разбор

Вычтем `3` из обеих сторон: `4x = 16`. Разделим обе стороны на `4`: `x = 4`. Подстановка даёт `4 × 4 + 3 = 19`, поэтому равенство верно.

### Границы модели

Этот первый тренажёр охватывает уравнения `ax + b = c` с целыми числами и положительным ненулевым `a`. Он не охватывает дробные коэффициенты, переменные по обе стороны, несколько переменных, системы или неравенства. Делить обе стороны можно только на ненулевое число; при решении неравенств умножение или деление на отрицательное число дополнительно меняет направление знака неравенства.

## English

### Goal

Solve an equation of the form `ax + b = c` by applying the same inverse operation to both sides, then check the answer by substitution.

### Idea and mechanism

An equals sign says the values on the left and right are the same. Adding or subtracting the same number on both sides preserves equality. Dividing both sides by the same non-zero number does too.

Example: `3x − 5 = 16`. Add `5` to both sides: `3x = 21`. Divide both sides by `3`: `x = 7`. We did not move `−5` across the equals sign as a separate rule; we applied the same operation to both sides.

Check by substituting `x = 7` into the original equation. The left side is `3 × 7 − 5 = 16`, which matches the right side, so the answer works.

### Explore and practise

In the trainer, first remove the constant term with the same operation on both sides. Then divide both sides by the coefficient of `x`. Substitute the result into the original equation. Each new example changes the coefficient, solution, and constant term.

### Question

Solve `4x + 3 = 19`. What value of `x` makes the equation true?

### Options

- `3`
- `4`
- `5`

### Answer

2

### Explanation

Subtract `3` from both sides: `4x = 16`. Divide both sides by `4`: `x = 4`. Substitution gives `4 × 4 + 3 = 19`, so the equality holds.

### Limits

This first trainer covers integer equations `ax + b = c` with positive, non-zero `a`. It does not cover fractional coefficients, variables on both sides, multiple variables, systems, or inequalities. Dividing both sides is valid only for a non-zero number. When solving inequalities, multiplying or dividing by a negative number also reverses the inequality sign.
